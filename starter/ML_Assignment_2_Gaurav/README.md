This repository implements the assignment workflow using raw flattened pixels, one roll-number-seeded stratified split, custom bootstrap bagging, and custom multiclass SAMME. Results and plots are generated by running the code; no result values are prefilled.

## Setup (Windows PowerShell)

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m src.run_experiments
```

If `py` is not found, install Python 3.12 or 3.13 from https://www.python.org/downloads/ and enable **Add python.exe to PATH**. In VS Code select `.venv` as the Python interpreter.

## Outputs

The script creates `results/` (CSV/JSON tables and saved split), and `figures/` (PNG plots). The first run downloads the Olivetti Faces dataset and therefore requires internet access. Run time depends on the laptop; the full experiment may take more than one hour.
